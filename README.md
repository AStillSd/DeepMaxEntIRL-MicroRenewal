# DeepMaxEntIRL-MicroRenewal

This repository provides a subset of anonymized study data to support methodological reproducibility.

The `example_data` directory currently includes coordinate data, environmental data, weather data, and Wi-Fi data.

The `core_code` directory contains core model implementations:
- `GCL_related`: Graph Contrastive Learning related spatial feature extraction code
- `IRL_related`: Deep Maximum Entropy Inverse Reinforcement Learning implementation

Due to privacy and confidentiality obligations, the complete raw dataset is not publicly available. The shared materials are intended to support understanding and reproduction of the analytical workflow rather than full replication of the empirical dataset.

This repository will be continuously updated as additional materials become available.
